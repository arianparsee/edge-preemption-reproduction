# arXiv v2 experiment specifications

These JSON files are non-executable Stage-13A specifications. They preserve
paper-explicit settings and name every unresolved scientific or implementation
dependency. A `null` run-control value is deliberate and must not be replaced by
a hidden default.

No file in this directory is evidence that the corresponding paper experiment
has been reproduced. The Southampton diagnostic has an auxiliary qualitative
path only; its official raw-trace path remains blocked.
